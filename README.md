# 📘 Pokédex

An interactive Pokédex inspired by the Pokémon anime! Explore, discover, and dive into the world of Pokémon in a simple and fun way. Gotta catch 'em all! 🎯

> ⚠️ The PokéAPI used in this project occasionally experiences instability, which may affect the quality or display of some images.

## 🌐 Live Demo

[View Live Demo](https://pokedex-1-chi.vercel.app/)

## ✨ Features

- 🌀 Interactive Pokémon carousel
- 🖱️ Click on a Pokémon to view its details
- 🧾 Detail page with visual stats
- 📱 Responsive layout for desktop and mobile

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- [PokéAPI](https://pokeapi.co/) — Pokémon data
- Vercel (Deploy)

## 🚀 Getting Started

```bash
git clone https://github.com/Joao-Mateus-Martins/Pokedex-app.git
cd Pokedex-app
```

Then open `index.html` directly in your browser — no build steps required.
